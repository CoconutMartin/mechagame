## Mech Naming

Names come from pre-colonial Filipino culture. Each mech has three parts:
- **Status class**: the social rank of the frame (light, medium, heavy).
- **Model name**: the specific frame.
- **Code**: 3 letters + number.

Format: `STATUS-class MODEL CODE`. Example: **Sagigilid-class Lawin LWN-101**.

### Code rules
- Letters: 3 letters from the Filipino name. Each code is unique.
- Generic number: first digit = class (1 = light, 2 = medium, 3 = heavy). Last two digits = part version. First release = 01. Example: LWN-101, then LWN-102.
- Animal number: the 3-digit phone area code of the animal's home (a sanctuary, park, or known habitat). Generic numbers never start with 0. Metro Manila (area code 2) is written 002. Versions get a letter suffix. Example: MMG-038, then MMG-038B. Some animals live across the whole country. For those, the area code is a place inside their range (marked *).
- Weapon and armor number: typical length in cm (3 digits). Shields use their longest side or diameter. See the "Size" column.
- Vessel number: typical length in meters (3 digits). See the "Size" column.
- Significant number: some other names use a number from their story or place. See "Significant numbers" at the end.

### Naming rules
- Gods and deities are allowed.
- Do not use Spanish loanwords (example: agila) or modern coinages (example: haribon).
- Do not use names of living ethnic groups as mech names.
